# Port-Engine
Port Engine is a mod for the “famous” game Age of History 2 Definitive Edition; this mod expands the gameplay of the base game even further.
Here are the features this mod adds:

- Trade: In the Technology Points section, there is a new technology upgrade called “Trade.” Each upgrade costs -5 Technology Points but increases trade by 0.25%+ to avoid embargoes.

- Law Points: Similar to Technology Points, these improve a civilization’s economy and politics.

- Greater Control Over Vassals: In the “Vassal Taxes” section, there are more options for controlling your vassals, but every action you take costs you Diplomacy points.

- Genocide: A button for the owner’s provinces (including those you’ve occupied). When you select the province where you want to use Genocide, it eliminates the possibility of rebellion but reduces your population and economy.

- New Ultimatums:
  - Ultimatum to leave the alliance
  - Ultimatum to hand over one of the victim's vassals

The engine is still under construction and being programmed, but I was able to add what I could; I’ll be adding more gameplay features later...
